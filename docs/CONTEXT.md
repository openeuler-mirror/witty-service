# Witty-Service IM Channel

本上下文描述 witty-service 如何把即时通信平台中的用户意图接入到它管理的 agent 上：用户在 IM 里私聊一个机器人，机器人背后的 agent 在其沙箱中完成工作，结果回到同一个私聊里。它不是一个独立的 IM 网关，而是 witty-service 面向外部对话入口的一层能力。

## Language

### 接入与身份

**渠道（Channel）**：
一个即时通信平台，例如企业微信、QQ、钉钉或飞书。
_Avoid_: 平台、IM、供应商

**渠道实例（Channel Instance）**：
某个渠道上一个具体机器人的凭据、运行配置与准入配置的整体；它是绑定 agent 的单位，也是会话路由的起点。
_Avoid_: 渠道配置、机器人账号、渠道

**渠道路由归属（Owner Ref）**：
调用方在建立渠道实例时附带的一个不透明归属标签。服务原样保存、原样返回，不解析其含义，也不据此做任何鉴权。
_Avoid_: 用户、账号、租户、所有者

**扫码接入（Provisioning）**：
用户扫描平台二维码，由平台授权或创建机器人并把凭据交给服务的过程。
_Avoid_: 绑定、注册、登录、授权

**接入尝试（Provisioning Attempt）**：
一次扫码接入从开始到成功、失败或过期之间的过程状态。
_Avoid_: 会话、任务、二维码

**手填凭据旁路（Manual Credential Binding）**：
扫码不可用、已过期或凭据遗失时，调用方直接提交平台凭据以完成接入的方式。
_Avoid_: 备用登录、兜底配置、手动登录

### 会话与路由

**会话路由（Conversation Route）**：
唯一确定一条入站消息属于哪个机器人、哪个聊天、以及其中哪个话题或线程的位置。
_Avoid_: 会话、会话键、Chat ID

**活动会话（Active Session）**：
某个会话路由当前绑定的 agent 会话。一个会话路由在任一时刻只有一条活动会话。
_Avoid_: 当前会话、默认会话、主会话

**会话来源（Session Origin）**：
一条 agent 会话由何种入口产生——控制台、IM 渠道或定时任务。
_Avoid_: 渠道标记、来源类型、入口

### 准入与凭据

**准入策略（Access Policy）**：
决定一次入站消息是否放行的规则，以及在放行之外是否允许其执行命令的附加判断。
_Avoid_: 白名单、权限、鉴权

**凭据掩码（Credential Mask）**：
凭据的可展示派生形式，用来在配置界面确认"这是哪一份凭据"，而不泄露凭据内容本身。
_Avoid_: 密文、脱敏串、指纹

**凭据引用（Credential Reference）**：
凭据在数据库中的表示形式：一个不含任何凭据信息的不透明标识。凭据本体不在库里，
而在凭据存储的同名文件里。它随实例 id 派生，因此重建实例不会复用别人的凭据。
_Avoid_: 密钥、密文、secretRef

**凭据存储（Credential Store）**：
存放渠道凭据本体的目录：目录 0700、一个凭据一个 0600 文件。权限不是"建议"而是
**使用前提**——group/other 可读即拒绝加载。它与主库是两个可分别备份、分别泄露的东西。
_Avoid_: 密钥库、保险箱、凭据表

### 回合与呈现

**回合（Turn）**：
从用户提交一条消息，到 agent 对该次提交产出终态之间的执行过程。
_Avoid_: 请求、任务、调用

**回合归属（Turn Ownership）**：
某个会话路由对其提交的特定回合享有停止权；该权利随回合结束而终止，不延伸至同一会话的后续回合。
_Avoid_: 会话锁、运行权、控制权

**占位消息（Placeholder Message）**：
回合开始时代替最终结果出现、随后被更新或被补发的消息。
_Avoid_: 加载提示、临时消息、进度条

**停滞窗口（Stall Window）**：
判定一个回合"看起来不再有进展"所需的静默时长。它随真实进展续期，因此不是回合的总时长上限。
_Avoid_: 超时、最大时长、截止时间

**延迟补发（Deferred Delivery）**：
前台等待被放弃之后，在后台继续监视同一回合，并把终态结果投递回原会话路由的机制。
_Avoid_: 后台重试、二次提交、轮询补发

**绑定闸门（Binding Gate）**：
延迟补发投递之前，校验会话路由当前绑定的会话是否仍与产生该结果的会话一致的条件。
_Avoid_: 会话校验、推送开关、会话锁定

**呈现意图（Presentation Intent）**：
agent 输出在进入渠道之前必须被保留的内容结构与格式含义，例如纯文本、进度、交互或产物。它不指定任何平台的控件或语法。
_Avoid_: 回答字符串、富文本、消息体

**渠道能力声明（Channel Capability Declaration）**：
一个渠道实例在当前平台条件与权限下能够可靠提供的能力集合。它是运行期事实，不是平台固有属性。
_Avoid_: 平台支持、SDK 能力、功能清单

**明确降级（Explicit Fallback）**：
渠道缺少所需能力时，在保持业务语义不变的前提下改用替代体验，并向用户说明这一限制。
_Avoid_: 兼容模式、静默忽略、兜底逻辑

**投递确定性（Delivery Certainty）**：
一次出站发送的结果分类：已投递、被平台确定性拒绝、或结果不确定。结果不确定时不得重发。
_Avoid_: 发送状态、成功失败、重试结果

### 建设纪律

**能力切片（Capability Slice）**：
围绕一个完整用户价值，从用户语义、安全策略到各渠道原生呈现与验收的端到端建设单元。
_Avoid_: 渠道任务、接口改造、功能点

**标杆渠道（Reference Channel）**：
在一项能力切片中最先完成真实闭环、其平台机制最适合验证该语义与体验的渠道。标杆渠道按能力选择，不是永久主渠道。
_Avoid_: 主渠道、默认渠道、首选渠道

**渠道行为基线（Channel Behavior Baseline）**：
在一项能力开始演进之前，某个渠道已经向用户提供的可验证体验集合。
_Avoid_: 当前实现、旧版本、现状

**等价接管（Parity Cutover）**：
新实现只有在覆盖渠道行为基线、通过回归并且具备回滚能力之后，才取得某项能力的唯一处理权。
_Avoid_: 替换、重写完成、上线

**命令回执（Command Receipt）**：
对一条命令的确认回复，只说明命令已被接受及其结果，不承载任务内容。
_Avoid_: 占位消息、提示、确认框
